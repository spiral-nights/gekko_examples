# `fibonacci_cli` Example

A native CLI application in Gleam that reads integer command-line arguments via `moonbitlang/core/env` and computes Fibonacci numbers using tail-call optimization.

## What It Demonstrates

- **CLI Argument Access (`gekko moonbit bind moonbitlang/core/env`):** Generates `src/ffi/env.gleam` and `moonbit/env_adapter/` from MoonBit's built-in `moonbitlang/core/env` package (`env.args() -> List(String)`).
- **Native Executable Builds (`gekko build --target native`):** Compiles straight to a standalone binary (`./fibonacci_cli.exe`) in the current directory.
- **Tail-Call Optimization:** `fib_loop` lowers to a MoonBit `for` loop, running in $O(n)$ time and $O(1)$ stack space.

## Project Layout

```text
fibonacci_cli/
├── gleam.toml                     # Gleam manifest (gleam_stdlib)
├── moonbit/
│   └── env_adapter/               # GENERATED by `gekko moonbit bind moonbitlang/core/env`
│       ├── env_adapter.mbt
│       └── moon.pkg
└── src/
    ├── ffi/
    │   └── env.gleam              # GENERATED by `gekko moonbit bind moonbitlang/core/env`
    └── fibonacci_cli.gleam        # Tail-recursive Fibonacci CLI + default fallback
```

## How It Was Created

1. Generated bindings for MoonBit's `env` package:
   ```bash
   gekko moonbit bind moonbitlang/core/env --root fibonacci_cli
   ```
2. Parsed integer arguments from `env.args()` in `src/fibonacci_cli.gleam` (defaulting to `[10, 20]` when no numeric arguments are provided, such as with `gekko run`).

## How to Run

First download dependencies if `build/packages/` is not already populated:

```bash
cd fibonacci_cli
gleam deps download
```

Build a native binary and pass numbers on the command line:

```bash
gekko build --target native
./fibonacci_cli.exe 10 20 50
# fib(10) = 55
# fib(20) = 6765
# fib(50) = 12586269025
```

Or run directly via `gekko run` (uses default inputs `10` and `20`):

```bash
gekko check
gekko run --target native
gekko run --target wasm
gekko run --target js
```
