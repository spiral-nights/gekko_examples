# `wit_greeter` Example

A minimal WebAssembly Component Model (WIT / WASI Preview 2) component implemented in Gleam and compiled via MoonBit + `wit-bindgen` + `wasm-tools`.

## What It Demonstrates

- **WIT Contract (`wit/world.wit` & `wit/deps/clocks/wall-clock.wit`):** Defines `package demo:greeter@0.1.0` with `world greeter`.
- **Standard WASI Host Import:** Imports `wasi:clocks/wall-clock@0.2.0` and calls `wall_clock.now()` from Gleam via `src/wit/wasi/clocks/wall_clock.gleam`. Because `wasi:clocks/wall-clock@0.2.0` is a built-in WASI Preview 2 interface, **`wasmtime` acts as the WASI host and provides it out of the box** — no custom host code is required.
- **Exported Interface & Record:** Exports `api.greet(u: user) -> string`, passing a WIT `record` (`User`) with an `option<string>` field across the Canonical ABI boundary and formatting the returned greeting with the host's Unix timestamp (`now.seconds`).

## Project Layout

```text
wit_greeter/
├── gleam.toml                             # Declares gleam_stdlib dependency
├── wit/
│   ├── world.wit                          # WIT interface (`api`) and `world greeter`
│   └── deps/clocks/wall-clock.wit         # Standard `wasi:clocks/wall-clock@0.2.0` WIT definition
└── src/
    ├── wit/                               # AUTO-GENERATED by `gekko wit gen` (do not edit manually)
    │   ├── api_types.gleam                # `User`
    │   └── wasi/clocks/
    │       ├── wall_clock_types.gleam     # `Datetime`
    │       └── wall_clock.gleam           # `@external(moonbit, ...)` stubs calling `wasi:clocks/wall-clock`
    └── api.gleam                          # Starter export stub generated once, then implemented by hand
```

## How It Was Created

1. **Defined the WIT schema:** Wrote `wit/world.wit` (importing `wasi:clocks/wall-clock@0.2.0` and exporting `api`) along with `wit/deps/clocks/wall-clock.wit`.
2. **Generated Gleam bindings and export stubs:** Ran `gekko wit gen`:
   ```bash
   gekko wit gen
   ```
   - Files under `src/wit/` are regenerated automatically whenever `gekko wit gen` is re-run.
   - `src/api.gleam` is created once and preserved on subsequent `gekko wit gen` runs.
3. **Implemented export:** Filled in `greet` inside `src/api.gleam` to read the wall clock via `wall_clock.now()`.

## How to Check & Build the Component

Ensure `wit-bindgen`, `wasm-tools`, and Gleam dependencies (`gleam deps download`) are available:

```bash
cd wit_greeter

# Type-check the bridged MoonBit + wit-bindgen workspace
gekko wit check

# Compile core Wasm and bundle the WASI Preview 2 component (.wasm)
gekko wit build --output dist/greeter.wasm
```

Inspect the resulting component interface with:

```bash
wasm-tools component wit dist/greeter.wasm
```

## How to Run with Wasmtime

Run the exported `api.greet` function directly under `wasmtime` (which provides `wasi:clocks/wall-clock@0.2.0` natively as the host):

```bash
wasmtime run --invoke 'greet({name: "Ada", title: some("Dr.")})' dist/greeter.wasm
# "Hello, Dr. Ada! (unix time: 1795319966)"

wasmtime run --invoke 'greet({name: "Grace", title: none})' dist/greeter.wasm
# "Hello, Grace! (unix time: 1795319966)"
```
