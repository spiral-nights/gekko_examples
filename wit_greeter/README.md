# `wit_greeter` Example

A WebAssembly Component Model (WIT / WASI Preview 2) component implemented in Gleam and compiled via MoonBit + `wit-bindgen` + `wasm-tools`.

## What It Demonstrates

- **WIT Contract (`wit/world.wit`):** Defines `package demo:greeter@0.1.0` with `world greeter`.
- **Host Imports:** Imports interface `logger` (`Level`, `log(lvl, msg)`) and calls it cleanly from Gleam via `src/wit/logger.gleam`.
- **Exported Interfaces & World Functions:** Exports `api` (`greet(u: User) -> Result(String, GreetingError)`, `sum_bytes(data: BitArray) -> Int`) and world function `ping(x: Int) -> Int`.
- **Component Types Across the Canonical ABI Boundary:** Exercises WIT `record` (`Meta`, `User`), `variant` (`GreetingError`), `enum` (`Level`), `flags` (`Perms`), `option<string>`, `result`, `list<string>`, `list<u8>` (`BitArray`), `u32`, `s32`, `u64`, and UTF-16 strings.

## Project Layout

```text
wit_greeter/
├── gleam.toml                   # Declares gleam_stdlib dependency
├── wit/
│   └── world.wit                # Authoritative WIT package/interface/world definitions
└── src/
    ├── wit/                     # AUTO-GENERATED by `gekko wit gen` (do not edit manually)
    │   ├── api_types.gleam      # `User`, `GreetingError`
    │   ├── logger.gleam         # `@external(moonbit, ...)` stub calling host `logger.log`
    │   ├── logger_types.gleam   # `Level`
    │   └── types_types.gleam    # `Perms`, `Meta`
    ├── api.gleam                # Starter export stub generated once, then implemented by hand
    └── greeter.gleam            # Starter world export stub (`ping`), implemented by hand
```

## How It Was Created

1. **Defined the WIT schema:** Wrote `wit/world.wit` specifying `logger`, `types`, `api`, and `world greeter`.
2. **Generated Gleam bindings and export stubs:** Ran `gekko wit gen` to generate the `src/wit/*.gleam` types/import bindings and the initial `src/api.gleam` / `src/greeter.gleam` stubs:
   ```bash
   gekko wit gen --root wit_greeter
   ```
   - Files under `src/wit/` are regenerated automatically whenever `gekko wit gen` is re-run.
   - Starter export files (`src/api.gleam`, `src/greeter.gleam`) are created once and preserved on subsequent `gekko wit gen` runs.
3. **Implemented exports:** Filled in `greet`, `sum_bytes`, and `ping` inside `src/api.gleam` and `src/greeter.gleam`.

## How to Check & Build the Component

Ensure `wit-bindgen`, `wasm-tools`, and Hex dependencies are available (`cd wit_greeter && gleam deps download` if needed):

```bash
# Type-check the bridged MoonBit + wit-bindgen workspace
gekko wit check --root wit_greeter

# Compile core Wasm and bundle the WASI Preview 2 component (.wasm)
gekko wit build \
  --root wit_greeter \
  --output wit_greeter/dist/greeter.wasm
```

You can also inspect the resulting component interface using `wasm-tools component wit wit_greeter/dist/greeter.wasm`.
